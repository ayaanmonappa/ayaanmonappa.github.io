# Ayaan Monappa: Engineering Portfolio

Static site. No build step: `index.html` plus the `assets/` folder.

## Publish on GitHub Pages
1. Create a public repo named `ayaanmonappa.github.io`.
2. Upload everything in this folder (keep `assets/` as a folder).
3. Settings > Pages > Source: Deploy from a branch, `main`, `/ (root)`.
4. The site goes live at https://ayaanmonappa.github.io within a minute or two.

Project pages use links like `#usv`, `#worker-risk`, `#glowin`, `#single-cell`, `#finding-george`, `#posture`, so you can link straight to one project.
